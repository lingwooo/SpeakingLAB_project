# IELTS Speaking Research Lab

A standalone English practice site with IELTS Speaking exercises, a guided Part 1 interview, browser voice input, and an informal English-level estimate.

## Publish with GitHub Pages

1. Create a GitHub repository named `SpeakingLAB_project` and add `index.html` and this README at the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. GitHub Pages will show the published address on the Pages settings screen.

The voice interview uses the browser's speech-recognition support. The page does not require a build step or server-side code.
